# BlockBlastAI v2.1 — Whole-Tray Learning Research

**Research package, NOT an iPhone update.** This package builds on v2.0's 10,080-game one-step learning experiment and adds a measured *whole-tray afterstate value model* using the existing v1.7 SMART SURVIVAL solver as the trusted generator of legal plans.

## New functionality implemented and tested

- **Real whole-tray state values:** The simulator records complete three-piece tray end positions, verified combo history, and actual remaining simulated moves until a game ends. It trains to predict future survival *after* the entire visible tray rather than rating only one placement.
- **12 afterstate signals:** open area, 3×3 landing slots, horizontal/vertical five-block slots, rectangular spaces, fit diversity across 28 known simulation shapes, fit diversity of large shapes, isolated holes, nearly completed lines, combo status, urgency and streak.
- **Group-isolated evaluation:** Split training and validation by entire simulated **game**, not adjacent moves or frames. Automatically search regularization values and save held-out MAE/R² versus a non-learning predictor.
- **Unseen-generator stress tests:** Mixed pieces, big-piece-biased trays, and a shifted 75%-hard-piece distribution. Identical seeded piece draws and transition legality checked for both policies.
- **Safety-first deployment gate:** Never allow the learned ranker to break a combo saved by the original plan, miss the immediately required clearing move, introduce more than one extra filled board square, remove a previously available 3×3 or five-long shape, or reduce overall shape diversity. It can only override a complete legal three-piece plan when its predicted improvement clears a conservative threshold.
- **Reproducibility and memory-safety checks:** Includes synthetic training board data, exact research C source, model JSON, a model-trainer, source for the v1.7 full-tray solver, unit tests and full benchmark logs. Unit tests passed under AddressSanitizer and UndefinedBehaviorSanitizer.

## Measured results (not real-game scores)

| Test | Existing v1.7 SMART SURVIVAL | New value-guided model |
|---|---:|---:|
| Group-held-out model MAE | Constant 26.98 moves | **21.21 moves** |
| Group-held-out predictive R² | constant predictor R² near zero | 0.094 |
| Unguarded 30 mixed-piece games, avg moves | **131.73** | 118.50 |
| Unguarded 30 stress games, avg moves | 32.53 | **34.00** |
| Fresh 40 mixed-piece games, guarded avg moves | 126.05 | 126.05 |
| Fresh 40 stress games, guarded avg moves | 29.975 | 29.975 |
| Fresh 40 *shifted hard* games, guarded avg moves | 25.00 | 25.00 |

The original unguarded trained model missed **6 avoidable last-chance combo clears** in its 30-game mixed evaluation. The strict guarded version missed **zero** in that test; in the fresh stress holdout, both algorithms recorded two instances, so it is not a universal no-miss guarantee.

**The learned ranker has NOT earned deployment.** The strict guard left only one override across all 120 fresh games; measured mean survival was unchanged and normal-game estimated score was slightly worse. Its predictive improvement has not translated into gameplay improvement. The existing iPhone .dylib should remain installed.

## Re-run on Linux/macOS

From this archive's root, with Clang/GCC, Python 3.10+ and the packages in `requirements-learning.txt`:

```bash
python -m pip install -r requirements-learning.txt
make verify
make collect         # 96 new seeded simulated games
make train           # group-held-out trajectory survival predictor
make benchmark       # 120 fresh paired game simulations, 3 distributions
```

`make benchmark` is a different set of game seeds from `make collect`, so evaluation does not train on the test sequences. A policy comparison must report **both survival and combo breaks**, plus legal moves, 10th-percentile survival and estimated points. The scoring formula, piece generator, and 3-move streak rule are not verified as the real mobile game's internals.

## Important limitations

This is a small regularized linear value model, not a neural network or a self-training iPhone app. It uses simulated trajectories generated by the already-strong v1.7 planner, so the model may inherit that planner's bias. It does not yet perform online lookahead across unknown future tray distributions, model uncertainty calibration or many thousands of *whole-tray* training episodes. No iPhone gameplay, YOLO vision or external proprietary website engine is contained or activated by this package.
