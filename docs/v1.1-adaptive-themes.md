# BlockBlastAI v1.1 BLINK — Replacement

This is the **new v1.1 blinking replacement**, intended to supersede the old v1.1 adaptive-fast download. Built from the v1.1 adaptive theme detector and with the original v1.0 highlight flash on every ReplayKit scan.

## Behaviors

- **Blinking like v1.0:** during every automatic screen capture, the in-game highlight guide layer and AI bubble are temporarily hidden to keep colored borders out of the scanner, then restored after the frame. The overlay can flicker or blink several times a second; this is intentional for this branch.
- **Adaptive color support retained:** blue/navy detector first, fallback geometry + per-frame background classifier for the wood/brown palette and related shades.
- **Fast decision making:** 0.24-second target scan timer (not a guaranteed latency), async v0.9 solver, and automatic detection of the recommended piece being placed.
- **Safety:** uncertain scans hide stale recommendations; panel can be moved or resized.

## Files and backups

GitHub's **feature/v1.1-adaptive-themes** branch now holds this new blinking source. The `v1.1-BLINK-replacement` artifact is its replacement download. Old artifacts and user-downloaded files cannot be retroactively erased from GitHub history or iPhone storage; manually delete the older v1.1 .dylib/ZIP in Files and retain the v1.0 known-good IPA as backup.

There was no tagged v1.1 GitHub Release to remove; v1.1 was distributed as a workflow artifact.

## Validation

The GitHub macOS smoke job tests old/wood screen detection, solver logic, simulator, and iOS ARM64 compilation. A completed green job is required before distributing the replacement. The device must still be checked for correct visible blinking and accurate play recommendations.
