# BlockBlastAI v0.9 — Advanced Offline Move Planner

**Status:** experimental branch `feature/v0.9-smart-ai`. The v0.8.2 screen-capture and vision code is preserved unchanged because it worked in a 10-minute user device session.

## What is new
- A 192-state beam search examines more legal three-piece move sequences than v0.8.2 (100 states).
- Scores include line clears, consecutive-clearing combos, occupied-space cost, isolated holes, board roughness, near-complete rows and columns, and placement room for 2×2, 2×3, 3×2, 3×3, four-block bars, and five-block bars.
- Proactively values *remaining currently available pieces* fitting after a candidate placement to avoid early dead ends.
- Deduplicates states by exact (64-bit board, used-piece mask) to spend its search budget on genuinely different boards.
- Keeps `BLSolve(board, pieces)`, `BLPiece`, `BLMove`, and `BLSolution` byte-for-byte compatible with the live overlay. No network, account, runtime memory allocation, external AI service or automatic placement.
- Deterministic. No machine-learning models are downloaded or run on the phone.

## Validation
- Existing solver, vision/orientation, and browser simulator tests.
- Independent `tests/test_solver_paths.c`: 300 deterministic randomized board+tray states, asserting every recommended move is legal and its resulting board and simultaneous line clears match an independent rules implementation.
- Paired benchmark against **actual working v0.8.2 solver**, preserved at `benchmark/v082_solver.c`, on **2,000 matching games with a 120-move cap**.
- A separate **1,000-seed holdout** using unseen seed offset 50,000 to reduce tuning overfit.
- Actual GitHub macOS toolchain compiles iOS ARM64 `.dylib`.
- No device validation of v0.9 yet: simulator piece generation is an approximation and not the real Block Blast generator. macOS solver timing does not prove iPhone latency. The installed v0.8.2 backup remains the known working version.

## How to test
Download the iPhone `.dylib` or iPhone ZIP from the successful GitHub Actions job's Artifacts area. Extract and inject **only** this dylib into a clean compatible IPA with KSign. Keep the original working IPA. Verify correct board, tray, highlights and 10+ minutes of gameplay before promoting.

**Never change the scanner to improve the solver.** Any future image-recognition changes need their own branch and on-device validation.
